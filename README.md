StudyBuddy – Responsive Landing Page

📌 About the Project

StudyBuddy is a responsive landing page designed to help students organize their learning, manage their study time, and stay productive.

The website features a clean and attractive black-and-white design with interactive elements and smooth navigation.

✨ Features

- Responsive website design
- Clean black-and-white UI
- Home, About, Features, and Contact sections
- Smooth scrolling navigation
- Interactive Explore Features button
- Back-to-top button
- Scroll-based section animations
- Mobile-friendly layout

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layout, and responsive design
- JavaScript – Interactivity and animations

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Run it using the Live Server extension.
5. Explore the StudyBuddy landing page in your browser.
